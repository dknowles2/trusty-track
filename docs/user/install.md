# Installing Trusty Track

Trusty Track can be installed in several different ways depending on your technical comfort level and how you plan to use it.

---

## Which method should I use?

| Method | Difficulty | Best for |
|--------|-----------|----------|
| [macOS App](install-mac.md) | Easy | Mac users who want to double-click and go |
| [Windows App](install-windows.md) | Easy | Windows users who want to double-click and go |
| [Docker](install-docker.md) | Medium | Running a permanent instance on a home server or NAS |
| [Raspberry Pi](install-raspberry-pi.md) | Medium | A dedicated plug-in appliance that starts automatically |
| [From Source](install-from-source.md) | Advanced | Developers who want to modify the code |

---

## Quick recommendations

**"I want to try it out on my Mac or Windows PC"**
→ Download the [macOS app](install-mac.md) or [Windows app](install-windows.md).

**"I want to run it permanently on my home network"**
→ Use [Docker](install-docker.md) on any server or NAS, or set up a [Raspberry Pi](install-raspberry-pi.md).

**"I want a dedicated plug-in appliance for race day"**
→ Set up a [Raspberry Pi](install-raspberry-pi.md).

**"I'm a developer"**
→ [Run from source](install-from-source.md).

---

## System requirements

| Method | OS | RAM | Disk |
|--------|-----|-----|------|
| macOS App | macOS 12 (Monterey) or later | 512 MB | 200 MB |
| Windows App | Windows 10 or later (64-bit) | 512 MB | 200 MB |
| Docker | Any OS with Docker Engine | 256 MB | 200 MB + data |
| Raspberry Pi | Raspberry Pi OS Lite (64-bit, Bookworm) | 1 GB recommended | 4 GB SD card minimum |
| From Source | macOS, Linux, Windows (WSL) | 512 MB | 500 MB |
